### 描述 / Description （943/4000 ✓）

密枢（Key Core）是一款面向开发者的本地 AI 密钥管理工具。它把分散在各处的 API 密钥收进一个整洁的钥匙包，并且能直接切换 Claude Code、Codex、Gemini 等 AI 编程工具正在使用的密钥。

【一处管理所有 AI 密钥】
· 卡片化展示，支持分组、标签、置顶与搜索
· 卡片底栏常驻快捷操作：复制密钥、复制请求地址、编辑、打开控制台
· 复制时不在界面上回显密钥

【130+ 供应商预设】
· 内置 OpenAI、Anthropic、Google Gemini、DeepSeek、通义千问、智谱、Kimi、MiniMax、硅基流动、OpenRouter 等供应商模板
· 搜索选择后自动填好请求地址与常用模型，也可以添加自定义供应商
· 供应商模板可在线更新

【一键切换工具密钥】
· 侧栏按工具查看当前使用的密钥：Claude Code、Claude Desktop、Codex、Gemini、OpenClaw
· 一把密钥可以启用到多个工具，「设为当前」即写入对应工具的配置文件
· 同时支持 OpenCode、Grok Build、Hermes、Pi、MiniMax Code 的配置写入

【密钥详情】
· 右侧抽屉查看密钥信息、请求地址和在各工具中的启用状态
· 「模型」标签页可查看与刷新该密钥可用的模型列表

【MCP 服务管理】
· 集中维护 MCP 服务，可从模板添加或导入 JSON
· 按工具启用，同步到 Cursor、Claude Code、Codex、Gemini、Claude Desktop、Windsurf、OpenClaw、OpenCode 等
· 同步页逐项对比本地与工具配置的差异，可选择推送、拉取或忽略；环境变量与请求头中的敏感字段自动打码；写入前列出将修改的文件供确认

【Skills 管理】
· 卡片浏览、分类筛选、详情查看
· 一键同步到各个 AI 工具

【安全与隐私】
· 可设置主密码，密钥加密存储
· 所有数据只保存在本机，不需要账号，不收集任何使用数据

【为 macOS 设计】
· 原生风格的侧栏与工具栏，支持浅色 / 深色外观
· 支持简体中文、繁体中文、English 等多种界面语言

### 隐私与支持 / Privacy & Support
