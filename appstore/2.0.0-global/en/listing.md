### 描述 / Description （1899/4000 ✓）

keycore is a local AI API key manager for developers. It gathers your scattered API keys into one tidy wallet and switches the key your AI coding tools — Claude Code, Codex, Gemini and more — are using.

ALL YOUR AI KEYS IN ONE PLACE
• Clean cards with groups, tags, pinning and search
• Always-visible quick actions: copy key, copy base URL, edit, open console
• Copying never echoes the key on screen

130+ PROVIDER PRESETS
• Built-in templates for OpenAI, Anthropic, Google Gemini, DeepSeek, Qwen, Zhipu, Kimi, MiniMax, SiliconFlow, OpenRouter and many more
• Pick a provider and the base URL and common models are filled in; custom providers supported
• Provider templates can be updated online

SWITCH KEYS PER TOOL
• The sidebar shows the key each tool is using: Claude Code, Claude Desktop, Codex, Gemini, OpenClaw
• Enable one key for several tools; "Set as current" writes it to that tool's config file
• Also writes configs for OpenCode, Grok Build, Hermes, Pi and MiniMax Code

KEY DETAILS
• A side drawer shows the key, base URL and where it is enabled
• A Models tab lists and refreshes the models available to the key

MCP SERVERS
• Maintain MCP servers centrally, from templates or imported JSON
• Enable per tool and sync to Cursor, Claude Code, Codex, Gemini, Claude Desktop, Windsurf, OpenClaw, OpenCode and more
• The sync view compares local and tool configs item by item — push, pull or ignore; secrets in env vars and headers are masked; files to be written are listed for confirmation

SKILLS
• Browse as cards, filter by category, view details
• Sync to your AI tools in one click

SECURITY & PRIVACY
• Optional master password; keys are stored encrypted
• Everything stays on your Mac — no account, no analytics, no tracking

DESIGNED FOR macOS
• Native-style sidebar and toolbar, light and dark appearance
• Interface in English, Simplified and Traditional Chinese and more

### 隐私与支持 / Privacy & Support 

Privacy: keycore does not collect or upload any personal or usage data and contains no analytics or tracking SDKs. Keys, MCP and Skills settings are stored only on your Mac, encrypted when a master password is set. The app goes online only when you refresh a model list or update provider templates, and reads or writes AI tool config files only when you ask it to.
